## Пример взаимодействия

**Мой запрос:**
> "В README.md на GitHub неправильно отображается блок кода. Вместо подсветки синтаксиса показывается просто текст со звездочками и тире. Как исправить форматирование Markdown?"

**Пример ответа LLM и реализованное решение:**
Чтобы исправить форматирование Markdown в README.md, нужно правильно использовать тройные обратные кавычки и избегать смешения синтаксиса. Каждый блок кода, открытый тройными обратными кавычками (```), должен быть закрыт такими же кавычками на отдельной строке. Внутри блока кода (между ``` и ```) не должно быть других элементов Markdown, таких как:
- Списки с дефисами (`-`) или звездочками (`*`)
- Заголовки с `##`
- Жирное или курсивное форматирование

Эти символы будут отображаться как обычный текст и сломают подсветку синтаксиса.
