# Домашнее задание: Snakemake Workflow

## Описание
Простейший Snakemake workflow для демонстрации выполнения домашнего задания.

## Запуск
```bash
# Клонируйте репозиторий
git clone https://github.com/ggleppp/hw-git-snakemake.git
cd hw-git-snakemake

# Установите Snakemake
pip3 install snakemake

# Запустите workflow
snakemake --cores 1

# Проверьте результат
cat results/output.txt
```

## Ожидаемый вывод
```
Hello from Snakemake! Workflow успешно выполнен.
```
